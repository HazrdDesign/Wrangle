# Wrangle 2.0.0

Wrangle 2 brings the redesigned panel and expanded expression library to the public release. This is the tested 1.6.1 build with the release version changed to 2.0.0; expression behavior and controls are unchanged.

- 40 bundled expressions with appropriate controllers and property targets.
- Compact library rows showing the name, Apply To property, and controller count.
- Rounded charcoal interface with a customizable accent color.
- Essentials shortcuts, category organization, and expression/controller capture.
- Corrected expression credits, including NoSleepCreative and original sources where matched.
- Automatic saved-library upgrades with backups, preserving custom edits and organization. No preset reset is required.

The owner completed After Effects testing and confirmed the plugin looks and works correctly. The preceding build passed 49 automated checks, browser layout checks, and signature verification.

Install **Wrangle-v2.0.0.zxp** using a ZXP installer, then reopen After Effects and choose Window > Extensions > Wrangle. See [the distribution README](README.txt) for installation, usage, backups, and optional preset reset/restore steps.
