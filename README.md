# Wrangle for After Effects

**Wrangle** is a powerful expression library manager for After Effects designed to streamline your workflow by providing instant access to curated expressions with automatic controller setup.

---

## ✨ Features

- **Categorized Library**: Quick access to Text, Time, Wiggle, Transform, Color, and 3D expressions.
- **Auto-Controllers**: Automatically adds Slider, Checkbox, Menu, and Layer controls to your target layer.
- **Smart Integration**: Built-in instructions on which properties to apply expressions to.
- **Customizable UI**: Adjust the panel theme and font size to fit your workspace.
- **Persistence**: Your custom expressions and categories are saved in OS-standard locations.

---

## 🚀 How to Use

### 1. Applying Expressions
Simply select a layer and property in After Effects, then click an expression in Wrangle.

- **Standard Click**: Applies the expression **AND** adds any required controllers (Sliders, etc.).
- **Ctrl + Click**: Applies the expression **ONLY** (ignores controllers).
- **Alt + Click**: Adds the **CONTROLLERS ONLY** (ignores the expression code).

### 2. Managing your Library
- **🔍 Add Expression**: Use the `+` button in the header to save your own snippets.
- **📁 Categories**: Create new categories or rename/edit existing ones to keep your library organized.
- **↕️ Reorder**: Drag and drop expressions or categories to rearrange them as you like.
- **🗑️ Delete**: Right-click or use the delete buttons to remove expressions you no longer need.

### 3. Customization
Click the **Settings (Gear Icon)** to adjust the panel's Hue or Font Size. Wrangle is designed to look premium and feel like a native part of the AE interface.

---

## 📂 Data & Backup
Wrangle saves your library data in update-safe system folders:

- **Windows**: `C:\Users\<username>\AppData\Roaming\Hazrd\Wrangle\data.json`
- **macOS**: `/Users/<username>/Library/Application Support/Hazrd/Wrangle/data.json`

You can back up this file or share it with other team members to sync your expression libraries. Any project-specific data added will persist across plugin updates and Adobe versions.
